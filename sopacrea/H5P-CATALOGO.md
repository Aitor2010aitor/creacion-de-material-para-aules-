# Catálogo oficial H5P revisado

Fuente principal: [H5P Content Types and Applications](https://h5p.org/content-types-and-applications).

Se revisaron las demos oficiales de los tipos disponibles y se conservaron sus URLs. SopaCrea integra el catálogo como biblioteca de selección con 54 tipos. Los tipos sopa de letras y crucigrama disponen de constructor interactivo completo; el resto se presenta con su demo oficial, categoría y campos iniciales para ampliar el constructor sin inventar esquemas incompatibles.

Tipos revisados: Interactive Video, Course Presentation, Branching Scenario, Accordion, Advent Calendar (beta), Agamotto, AR Scavenger, Arithmetic Quiz, Audio Recorder, Chart, Collage, Cornell Notes, Crossword, Dialog Cards, Dictation, Documentation Tool, Drag and Drop, Drag the Words, Essay, Fill in the Blanks, Find Multiple Hotspots, Find the Hotspot, Find the words, Flashcards, Game Map, Guess the Answer, Iframe Embedder, Image Hotspots, Image Juxtaposition, Image pairing, Image Sequencing, Image Slider, Impressive Presentation (ALPHA), Information Wall, Interactive Book, KewAr Code, Mark the Words, Memory Game, Multimedia Choice, Multiple Choice, Page, Personality Quiz, Questionnaire, Quiz (Question Set), Single Choice Set, Sort the Paragraphs, Speak the Words, Speak the Words Set, Structure Strip, Summary, Timeline, True/False Question, Virtual Tour (360), Complex fill the blanks. La lista de la galería oficial aporta 54 entradas al catálogo.

La investigación de demos confirmó diferencias importantes: algunos tipos anidan otros contenidos H5P; muchos guardan listas de elementos en `content/content.json`; los tipos multimedia dependen de archivos o URLs; y los tipos de voz, cámara, AR o vídeo dependen de permisos y recursos externos.
